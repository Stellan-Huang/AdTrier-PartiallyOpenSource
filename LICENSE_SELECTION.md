# License decision required before public release

No license file is included in this archive because choosing a license changes the rights granted to other people and organizations.

A public GitHub repository without a license is not automatically open source. Before publishing, decide whether to use (for example) MIT, Apache-2.0, or another license that matches your intentions and any third-party code/assets obligations.

Do not add a permissive license until you are comfortable granting the permissions it contains. Also verify ownership and licensing for any assets or dependencies you add later.
